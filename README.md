# Expedia Travel Analytics Dashboard

## Project Overview

This Power BI dashboard analyzes travel booking performance across multiple dimensions including customers, channels, revenue, profitability, and booking behavior.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling

## Dashboard Pages

- Home
- Gross Overview
- Customer Analysis
- Channel Analysis
- Gross Breakdown

## Key Metrics

- Gross Booking
- Net Margin
- Booking Count
- Conversion Rate
- Customer Segmentation
- Channel Performance
- Revenue by Device
- Booking Status Analysis

## Data Model

Star Schema Data Model with Fact and Dimension tables.
